# FixFair

**Fair prices for car repairs, explained by AI.**

FixFair is a Torob-style price comparison experience for the car repair market in Iran. Describe your problem in plain Persian and get a ranked list of nearby shops with price ranges, a clear explanation of the best choice, and a warning if a quote looks inflated.

> Built as a demo for the AI Product Engineer challenge at Torob.
> Status: work in progress. See [PROGRESS.md](./PROGRESS.md).

## The problem

Car repair prices are opaque. The same fender repair can cost twice as much in one shop as in another, and most people have no way to know if they are being overcharged.

## How it works

1. **Understand:** an LLM turns a messy request (`گلگیر جلوی پراید خورده، تهران`) into a structured query: service, car model, city, intent.
2. **Normalize:** raw price data from different sources (`گلگیر ۲ میلیون با رنگ`, `صافکاری+رنگ گلگیر: ۲.۵ت`) is converted into one standard record.
3. **Rank:** offers are ranked by the user's intent: cheapest, nearest, best rated, or best value.
4. **Explain:** the LLM explains the top choice using real numbers ("15% below the city average, rated 4.6, but 8 km away").
5. **Protect:** prices far above the market average are flagged.

Prices are shown as **ranges**, because repair cost depends on damage level and car model.

## Scope of this demo

- One city: Tehran
- 100-300 price records, collected manually
- Natural-language search, ranking, AI explanation, map, simple ratings

## Data transparency

| Type      | Description                                                                              |
| --------- | ---------------------------------------------------------------------------------------- |
| Real      | Collected manually from public listings and shops. Each record keeps its source and date |
| Synthetic | Generated by an LLM from real examples to enlarge the demo set. Marked `is_real = false` |

No Torob data is used. No full ads or images are copied.

## Tech stack

- TypeScript, Next.js (App Router), Tailwind CSS, shadcn/ui
- PostgreSQL (+ PostGIS)
- MapLibre GL + OpenStreetMap
- Claude API with Zod-validated structured output
- Vitest and Playwright

## Getting started

```bash
git clone <repo-url>
cd fixfair
npm install
cp .env.example .env   # add your API keys
npm run db:seed
npm run dev
```

## Project structure

```
src/
  app/          # Next.js pages and API routes
  lib/ai/       # query parser, normalizer, explainer
  lib/ranking/  # ranking and price-anomaly logic
  db/           # schema and seed
data/           # collected price records
evals/          # evaluation set and scripts
```
